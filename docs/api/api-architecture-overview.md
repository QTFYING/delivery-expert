# API 架构总览

> 本文档只维护 Admin / Tenant / H5 三端 API 的全局边界与共享事实源规则
> 具体请求/响应结构、分页、`nullable` 与示例以 Swagger 和共享 `contracts` 为准

## 一、全局事实源

- 枚举事实源统一维护在 `packages/types/src/enums/`
- 请求、响应和资源结构统一维护在 `packages/types/src/contracts/`
- 通用分页与响应包装等共享结构统一维护在 `packages/types/src/common/`
- Swagger 负责传输结构、可选项、`nullable` 与示例展示
- `docs/api` 只补充业务语义、状态流转、边界和冲突裁决，不维护第二份结构说明书

## 二、访问边界

| 端     | 边界                                                   |
| ------ | ------------------------------------------------------ |
| Admin  | 平台运营视角，跨租户查看和管理平台数据                 |
| Tenant | 商户 SaaS 视角，所有业务数据自动按当前 `tenantId` 隔离 |
| H5     | 客户支付视角，通过订单 H5 入口令牌访问单个公开订单页面 |

H5 入口令牌只用于路由到订单公开页面，不承载收货人身份认证，也不是支付单标识。

## 三、全局响应与错误码

后台接口统一下发 `code / message / data` 包装，具体结构以 Swagger 与共享 contracts 为准。

`x-trace-id` 仅用于前端反馈问题和服务端日志定位，不作为业务幂等键，也不进入业务请求或响应结构。

| code   | 含义                           |
| ------ | ------------------------------ |
| `0`    | 成功                           |
| `1001` | 订单已支付，禁止重复操作       |
| `1002` | 二维码已过期                   |
| `1003` | 支付中，禁止并发发起           |
| `1004` | 当前租户支付渠道不可用         |
| `1005` | 订单已超过租户支付有效期       |
| `1006` | 当前商户暂不可收款             |
| `4001` | 未登录或 Token 已失效          |
| `4003` | 无权限访问该资源               |
| `4004` | 资源不存在                     |
| `4006` | 权限已变更，请刷新当前用户信息 |

`4006` 用于后台登录态请求的权限快照失效感知。前端收到后应重新调用 `GET /auth/me` 刷新当前用户权限快照。

## 四、金额与时间

- API 金额默认以元为单位
- 少数支付字段若标注为“元单位字符串”，前端按字符串消费，不自行改价或换算
- 日期时间字段以 ISO 8601 UTC 格式传输，前端展示时按业务要求转换

## 五、三端关键边界

### H5 支付

- H5 支付状态是订单在 H5 页面上的聚合展示状态，不是 `payment_orders.status` 的无条件直传
- 在线支付只在用户主动发起时创建支付尝试
- 线下登记进入 `pending_verification`，由 Tenant 财务确认后写入收款流水
- 租户状态为 `paused` 或 `onboarding` 时，H5 在线支付和线下登记都被阻断

### Tenant

- Tenant 请求不传 `tenantId`，由服务端从登录态注入
- 订单导入采用“模板 -> 预检 -> 正式导入 -> 任务轮询”的链路
- Tenant 侧采用单角色功能权限 RBAC，当前阶段一个用户只绑定一个角色
- 打印配置只存黑盒 JSON，持久化维度为 `tenantId + importTemplateId`
- 支付渠道配置以 `channel` 为资源维度，实际收款渠道由租户主记录上的 `activePaymentChannel` 表达

### Admin

- Admin 用户 `tenantId = null`
- Admin 可以跨租户查看订单与收款数据，但不承担 Tenant 侧订单导入、打印、催款或线下确认动作
- Admin 对租户支付配置的操作是运营兜底，不替代 Tenant 侧配置归属
- 当前未落地的 Admin 规划能力不作为 Swagger、contracts 或前端开发事实源

### 公共能力

#### 文件上传

- 申请上传凭证：**POST** `/uploads/policies`
- 确认上传完成 **POST** `/uploads/{uploadId}/complete`
